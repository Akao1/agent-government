# 官员记忆规范（档案重建式）

工程上能实现的不是"人脑式记忆"，是"档案重建式记忆"——智能体每次唤醒靠读档案重建身份。官员专业性＝判断规则+踩坑记录+用户历史反馈，全是显性知识，档案完全承载。不需要造人脑，需要造好的是**档案制度**。

## 三级记忆（借"起居注→实录→国史"）

| 层 | 内容 | 写入者 | 触发 |
|---|---|---|---|
| **起居注** | 逐任务流水：本任判断、结果、踩坑、用户反馈 | 当任官员自己 | 每单任务收尾时（约定动作） |
| **实录** | 起居注超阈值后提炼的任内要点 | **翰林专掌**（契约见 [historian](../templates/historian.md)；本官、御史、次任均不修，杜绝御史兼职与次任互惠粉饰） | 阈值触发（如单文件超百段）；原始流水归档不删 |
| **国史** | 已验证稳定结论、用户已确认的偏好性反馈 | 翰林提名，御史核档通过后**报用户朱批准入** | 三重准入（提名→核档→朱批）；未经朱批的提名停留在实录层 |

修史权分离的用意：防止官员自己给自己粉饰（历史上起居注皇帝不得观览，同一道理）。

## 开局方式

每单任务新开智能体：喂实录+国史+按任务领域检索相关起居注片段，**不全读**（控制 token）。每次新开＝新白纸，天然免疫锚定效应和跨项目串味。

## 人脑记忆 vs 档案记忆

| 特性 | 人脑 | 档案 | 对官员职责的影响 |
|---|---|---|---|
| 召回方式 | 联想式 | 显式检索 | 官员要的恰是精确引用，联想是事故源 |
| 遗忘 | 自然筛选 | 永不遗忘只膨胀 | 需要定期修史压缩 |
| 错误记忆 | 会自我怀疑 | 错了也当真 | 需要御史核档 |
| 可审计 | 不可 | 每条可溯源 | **优于人脑**——责任链要的就是这个 |

## 铁律

1. **条目两类分级**：每条必标"已验证结论"或"当时假设"，不得混写。防止错误判断入档后每任都带着错。
2. **双权威**：用户的偏好以用户的全局偏好文件为最高权威，官员档案**只记职务判断、不记用户偏好**；发现冲突以用户文件为准。
3. **案卷不出区**：档案只记制度记忆（怎么拟票/审票/巡按的手艺与教训），不记任何项目的具体事实、客户状态、具体交付内容。
4. **并行防分叉**：同一官员需同时实体化两份时，先到者对档案文件持锁（任何文件锁机制），后到者只读；起居注追加前重读文件。
5. **追写时机**：起居注是收尾约定动作，与台账登记同批完成，不单独等用户提醒。
6. **修史权分离**：翰林专掌修史（署名+溯源引用），本官不修自己的实录，御史只核不修；翰林不修翰林自己的实录（由次任翰林或御史指定修史者提炼）。
7. **翰林史鉴与功过**：每次修史顺带产出"史鉴"（本任教训）与"功过摘要"（基于起居注证据的定性归纳，不做分数），供周报引用。
8. **起居注台账互核（双记制）**：本官自记是"记言"，系统台账（任务登记/流水线/证据文件）是"记动"——每条起居注须带台账锚点并可对上其一；**对不上台账的条目视为孤证**，御史核档时降级为"当时假设"，不得作为实录提炼依据。左史记言、右史记动，缺一则孤证。

## 目录结构示例

```
agents/records/
  README.md            ← 本规范
  内阁/
    首揆.md            ← 实录+国史（提炼层）
    次揆甲.md
    次揆乙.md
    log/首揆-YYYY-MM.md ← 起居注（逐任务流水）
  御史.md
  御史-log/
```
