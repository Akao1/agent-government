# 官制总纲（开源版）

本文件定义"三省六部 + 内阁 + 御史台"官制与工具体系的映射。**官制是命名与职责的框架，不是新的执行程序**——所有调度、占用、收尾仍走你现有的机制（任务流水线、文件锁、定时任务），官制不新建任何执行机制。

## 一、全图

```
皇帝（用户）── 批红（大事必朱批，无代理、无默认、不设自动批准）
  │
内阁（跨项目·三揆·只票拟不执行）
  │  输出"谕旨"：处理决定 + 路由 + 是否请批红
  │  密揭/阁议/会签三级 · 拟票互不可见 · 分歧原样保留
  │      ↑封驳谕旨：门下省（侍中）   ↑封驳票拟：御史台
  ↓谕旨（小事直达执行，大事待批红后下达）
三省六部（不入阁·行政体系）
  中书省：接谕旨草"题本"（任务契约/设计/验收标准）
  门下省：封驳谕旨 + 属官复核交付物
  尚书省：仆射＝当前工作区会话模型（尚书令＝任务调度脚本，虚悬）
    └─ 六部（各工作区职能分区）：吏/户/礼/兵/刑/工
御史台（跨项目·独立）：巡按六部清单 · 发布后抽验 · 专项弹劾
  核档（官员宦历 vs 实际证据）· 销案复核 · 封驳票拟
```

## 二、两种文书的区分（制度命根）

| 文书 | 出自 | 回答的问题 | 形态 |
|---|---|---|---|
| **谕旨**（票拟产物） | 内阁三揆 | 做不做、走哪条流程、哪个部主办、要不要请批红 | 几行决定+路由 |
| **题本**（任务契约） | 中书省 | 怎么做、改哪些文件、做到什么算合格 | 详细任务契约/设计文档 |

内阁答"决策"，中书省答"执行设计"。两层永不清浑：内阁不写验收标准，中书省不决定路由。

## 三、三省＝工序（跨项目），六部＝职能（本区）

- **三省是工序，不可轮值**：草诏、封驳、执行三道工序互相制衡的前提是身份分离。同一任务内拟票者（内阁）≠封驳者（门下/御史）≠执行者（尚书省）≠批红者（用户）。
- **六部是职能分区，各自守一摊**：见 [职能分区.md](职能分区.md)。会签时各部从本部专业视角审票，**部职不入阁**（阁臣不掌部、部官不代批红）。
- **衙署在全局，办差在本区**：跨区官员（三揆、侍中、御史）的制度记忆档案存全局 `agents/records/`，当值时下到任务所在工作区读本区案卷办本区事。
- **铁律：制度记忆跨区，案卷不出区**。官员的"手艺"（怎么拟票、什么算好票）跟着官走；官员在 A 项目办的具体案卷（项目事实、客户状态）不得带入 B 项目。跨区的是官，不是案。

## 四、内阁（三揆制）

契约见 [../templates/grand-secretary.md](../templates/grand-secretary.md)。要点：

1. 三个独立智能体：首揆+次揆×2，各有宦历档案，风格互补（原型：明代三杨辅政——杨士奇长内政、杨荣长边务、杨溥长德操）。
2. 主拟人按任务领域定（对该领域宦历最深者主拟并署名），**不轮值、不选举、不推举**。
3. 三级票拟控成本：密揭（小事一揆单票多视角）→ 阁议（中事三揆各拟互不可见）→ 会签（大事三揆+相关部阁老）。
4. 三不准：不准吞分歧、不准代批红、不准在票拟阶段执行（拟票期间不动任何业务文件）。

## 五、批红权（红线条款）

1. **批红权专属用户**，无代理、无默认值、不设自动批准钩子。历史教训：明代皇帝怠政→批红流于形式→内阁膨胀为事实宰相；工程映射：长期"都按票拟办"＝三揆变成真政府。
2. **必批事项**：谕旨涉及全局规则修改、不可逆操作（删除/覆盖/归档原件）、对外发布（外发/上传/公开发布）、付费或开通资源时，未经批红不得下达执行。这条没有快捷通道。
3. 小事走密揭直呈：用户看过即可，不要求逐条回复——"看过"以不否决为准，但必批事项除外。

## 六、御史台

契约见 [../templates/censor.md](../templates/censor.md)。要点：

1. **独立**：御史不参与任何任务的执行阶段，不得是同一任务的任何阶段执行者；查自己＝同流合污。
2. **巡按不驻防**：一个御史智能体按六部检查清单巡按（明代巡按一年一换防、严禁久驻，防勾结），不是每部常驻一个人格。触发：定期巡按（定时任务）+ 发布后抽验 + 台账异常专项弹劾。
3. **风闻奏事**：低置信度疑点可上报但必须标注置信度；不把"没证据"当"有问题"，也不当"没问题"。
4. **只查不改**：御史发现问题→上报→内阁票拟→（小问题密揭/大问题批红）→交责任部执行→御史销案复核。御史本人无修改权。
5. **核档**：巡按含抽验官员宦历档案与实际证据是否相符；档案条目须能溯源到本区证据文件。

## 八、周报（轻量化）

1. 挂现有定时审计节拍，不另起炉灶。
2. **聚合不创作**：从台账、审计报告、流水线记录聚合编辑；内阁做汇总官不做作家。
3. **异常驱动、无事平安帖**：正常部门一行"本部无事"；只展开异常与待批事项。历史教训：文书层级一多就积压，周报变废纸。

## 九、防退化条款

1. 批红权不可闲置（见第五节）。
2. 御史台不得成为瓶颈：常规任务抽样审（发布后抽验 1 项），不强制全套审计。
3. 内阁不得膨胀：只出纸不动手，产出永远是文书；谕旨必批事项未经批红不得下达。
4. 官制不扩张：新增任何"官职"须先答两个问题——对应什么真实缺口？对应什么可执行检查？答不上来不设（不设东西厂）。
5. 快捷通道保留：小事不过内阁（密揭或直答），对应"小改动可缩短交付"。
